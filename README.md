# UTC-NF92

Site de gestion d'une auto-école — projet de l'UV **NF92** de l'UTC, en PHP/MySQL sans framework.

| | Fonctionnalités |
|---|---|
| **Élèves** | inscription, consultation, validation et notation |
| **Séances** | création, inscription et désinscription des élèves, validation |
| **Thèmes** | ajout et suppression des thèmes de conduite |
| **Calendrier** | visualisation du planning d'un élève |

## Mise en route

Le site attend une base MySQL : renseignez hôte, base, utilisateur et mot de passe dans [`connexion.php`](connexion.php) (les valeurs sont volontairement vides dans le dépôt), puis servez le dossier avec PHP.
